# Product Information System

Mini Project 1 — Product Information System.

## Struktur
- `products.php` — Data Layer
- `functions.php` — Processing Layer
- `index.php` — Presentation Layer

## Konsep yang digunakan
- Multidimensional array untuk data produk
- `require_once`
- `foreach`
- `hitungNilaiStok()`
- `hitungTotalNilaiStok()`
- `stokKritis()` dengan batas stok kurang dari 3
- Perhitungan dan format nilai Rupiah

## Menjalankan
Letakkan folder ini di `htdocs`, kemudian buka:

`http://localhost/product-information-system/`
